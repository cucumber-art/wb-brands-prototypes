# WB Бренды 2.0

В репозитории хранится одна актуальная версия интерактивного прототипа.

## Открыть прототип

- Основная страница: `index.html`
- Прямой файл: `wb-brands-2/prototype.html`
- Документ экранов: `wb-brands-2/wireframes.html`

При публикации через GitHub Pages корневая страница автоматически перенаправляет на актуальный прототип.

## Структура

```text
index.html                 — переход на актуальный прототип
robots.txt                 — запрет индексации поисковиками
wb-brands-2/
  prototype.html           — актуальный кликабельный прототип
  wireframes.html          — документ экранов
  assets/                  — стили, скрипты и изображения
```

## Правило обновления

1. Менять только файлы в `wb-brands-2/`.
2. Перед изменениями создавать отдельную ветку.
3. Проверять прототип до слияния в `main`.
4. Не загружать в репозиторий пароли, токены и рабочие данные пользователей.

Публичный GitHub Pages для этого репозитория следует держать отключённым, если прототип предназначен только владельцу.
