# WB Бренды 2.0

## Актуальная версия

**[Открыть последний прототип](https://cucumber-art.github.io/wb-brands-prototypes/wb-brands-2/prototype.html#home/default)**

Это единственная актуальная публичная ссылка. Добавь её в закладки браузера.

## Файлы

- `wb-brands-2/prototype.html` — актуальный кликабельный прототип.
- `wb-brands-2/wireframes.html` — документ экранов.
- `wb-brands-2/assets/` — стили, скрипты, данные и изображения.
- `index.html` — автоматически перенаправляет на актуальный прототип.

## Как обновлять

1. Создать отдельную ветку.
2. Внести изменения только в `wb-brands-2/`.
3. Проверить прототип.
4. Слить изменения в `main`.
5. Дождаться успешного деплоя GitHub Pages.

Не загружать в репозиторий пароли, токены и рабочие данные пользователей.
